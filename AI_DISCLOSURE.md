# AI usage disclosure

This project (build scripts, documentation and patches for the mainline-Linux port of the realme GT Neo 2, and the
kernel branch in its companion repo) was developed with substantial assistance from an AI coding assistant
(Claude Code by Anthropic), directed by the repository owner. This includes research, code and
patch authoring, kernel/KernelSU/SUSFS integration, build debugging, and writing the docs.

- Everything here is **experimental and only partly tested on hardware**; it is provided **as-is,
  without warranty**. Flashing custom firmware can brick your device or lose data. Back up first.
- AI-assisted commits carry a `Co-Authored-By: Claude` trailer. Docs may contain AI-written
  analysis that can be wrong or out of date; verify before relying on it.
- Extracted/downloaded third-party files were treated as untrusted data while working.
- The AI did not flash any device; flashing was always done manually by the owner.
